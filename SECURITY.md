## Reporting a Vulnerability

If you discover a potential security vulnerability within **CLASSY_CS** (such as token handling in Convex authentication, client-side input validation bypasses, or data export vulnerabilities), please report it responsibly:

1. **Do not create a public issue**: Please do not open public GitHub issues or discussions for sensitive security bugs.
2. **Contact Privately**: Send details via GitHub Security Advisory (preferred) or email the maintainer via privacy-safe developer contact: `211186833+RONALD-REX-7@users.noreply.github.com`.
3. **Include Details**: Provide a description of the vulnerability, reproduction steps or test payload, and expected vs observed security impact.

Reports will be reviewed and addressed promptly.
